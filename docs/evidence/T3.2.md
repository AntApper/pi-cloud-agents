## Security & Architecture Verification Checklist
- `StackDeployer.deployStack` uses CloudFormation change sets (`CREATE` / `UPDATE`), gracefully handles `NO_CHANGES` change set status as a successful no-op, and streams chronological stack events.
- On stack creation failure or rollback, failure diagnostics are extracted from `ResourceStatusReason` across failed stack events and reported in `StackDeployError`.
- `StackDeployer.deleteStack` deletes stacks and streams deletion progress until `DELETE_COMPLETE`.
- `StackDeployer.emptyBucket` performs paginated deletion of all versioned objects and delete markers prior to stack or bucket deletion.
