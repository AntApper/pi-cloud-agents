## Plan
- Implement `runner/hooks.ts` HTTP server on `0.0.0.0:9000` (or `HOOK_PORT`) with lifecycle routes under `/aws/lambda-microvms/runtime/v1/`.
- Handle `GET /ready` (503 while initializing, 200 once ready), `/validate` (self-check on binary/git/disk), and `POST /run` (< 200 ms latency).
- Handle `POST /resume`, `/suspend`, and `/terminate` with bounded deadlines, answering 200 even if handlers hang or throw.
- Support idempotency and safe 200 responses for unknown hook routes; handle invalid payload gracefully by marking run failed.
- Write unit tests in `tests/unit/runner-hooks.test.ts` covering status codes, latency, timeouts, and idempotency.
- Validate with `npm run test:unit -- runner-hooks` and `npm run check`.
