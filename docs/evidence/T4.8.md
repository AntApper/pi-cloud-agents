# Evidence: T4.8 — Control commands: stop, suspend, resume, logs, pr, shell

## Plan
1. Implement `core/controls.ts` for orchestrating stop, suspend, resume, logs querying & tailing, PR creation, and shell auth token minting.
2. Implement `extension/commands/controls.ts` providing command handlers for `/cloud stop`, `/cloud suspend`, `/cloud resume`, `/cloud logs`, `/cloud pr`, and `/cloud shell`.
3. Wire all 6 control commands into `extension/router.ts` and export through `core/index.ts`.
4. Add unit tests in `tests/unit/cloud-controls.test.ts` mocking AWS clients (LambdaMicrovms, CloudWatchLogs, S3) and verifying all lifecycle state transitions, polling, and security rules.
5. Validate with `npm run check`.

## Implementation Details
- `core/controls.ts`:
  - `stopCloudRun`: Confirms run state, sends `/v1/checkpoint` to runner to save last work and flush session if running, executes `TerminateMicrovmCommand`, and marks manifest `terminated` in S3.
  - `suspendCloudRun`: Executes `SuspendMicrovmCommand`, polls `GetMicrovmCommand` until `SUSPENDED`, and updates manifest.
  - `resumeCloudRun`: Executes `ResumeMicrovmCommand`, polls `GetMicrovmCommand` until `RUNNING`, and updates manifest.
  - `fetchCloudRunLogs` & `tailCloudRunLogs`: Queries CloudWatch Logs `/aws/lambda/microvms/<imageName>` via `FilterLogEventsCommand` with `runId` filtering and real-time polling every 2s.
  - `createCloudRunPullRequest`: Requests runner to publish work branch and create GitHub PR via `/v1/finalize`, with fallback manual commands (`git push` + `gh pr create`).
  - `createCloudRunShellSession`: Mints short-lived (15 min) auth token via `CreateMicrovmAuthTokenCommand` scoped strictly to port 8022 (`lambda-microvms.port.8022`), enforcing token privacy rules (tokens never logged).
- `extension/commands/controls.ts`:
  - Implements command handlers with interactive `PiPrompter` run selection and confirmation dialogs.
- `extension/router.ts`:
  - Wired subcommands: `stop`, `suspend`, `resume`, `logs`, `pr`, `shell`.
- `tests/unit/cloud-controls.test.ts`:
  - 12 unit tests covering all 6 commands, state polling, log tailing cancellation, PR URL retrieval, shell token generation, and command handlers.
