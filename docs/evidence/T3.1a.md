## Security & Architecture Verification Checklist
- `infra/core.yaml` creates `ArtifactBucket` (private, encrypted, versioned, lifecycle expiration for `runs/`), `ImageLogGroup`, `ControllerLogGroup`, `BuildRole`, `ExecutionRole`, and `OperatorPolicy`.
- `BuildRole` & `ExecutionRole` both require `aws:SourceAccount: <AccountId>` confused-deputy protection and allow only `lambda.amazonaws.com`.
- `ExecutionRole` contains zero `lambda:*` permissions, enforcing external controller-driven lifecycle model.
- `OperatorPolicy` grants strictly scoped CloudFormation, S3, Secrets Manager, and Lambda MicroVM privileges, only using wildcard `*` for read-only discovery actions (`sts:GetCallerIdentity`, `ListManagedMicrovmImages`, `ListMicrovmImages`, `ListMicrovms`, `ListSecrets`, `GetServiceQuota`).
- Full IAM permission boundaries documented in `docs/iam.md`.
