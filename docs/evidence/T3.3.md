## Security & Architecture Verification Checklist
- `uploadArtifactIfMissing`: Uses S3 `HeadObject` and SHA-256 metadata verification to skip redundant artifact uploads when content-addressed keys match.
- `resolveLatestBaseImage`: Discovers the latest available AL2023 managed MicroVM base image and active version with `AVAILABLE` status.
- `MicrovmImageManager.deployImageArtifacts`: Generates deterministic content-addressed keys (`runner/<sha256>.zip`, `controller/<sha256>.zip`) and uploads artifacts.
- `MicrovmImageManager.waitForImageReady`: Continuously polls `GetMicrovmImage` and `GetMicrovmImageVersion` until the target version is `ACTIVE`/`SUCCESSFUL`. On build failure, fetches the last 50 lines from CloudWatch log group `/aws/lambda/microvms/<imageName>` to embed actionable diagnostics in `MicrovmImageBuildError`.
- `MicrovmImageManager.describeImage`: Extracts image ARN, version, runner SHA, pi version, base image details, and memory snapshot bytes for drift analysis and observability.
- `MicrovmImageManager.checkImageDrift`: Accurately detects drift between local runner artifact SHA and active image version.
- `MicrovmImageManager.pruneVersions`: Prunes older image versions while retaining the top active versions (default keep = 2) via `DeleteMicrovmImageVersionCommand` to minimize AWS snapshot storage costs.
- Fully unblocks Task T4.3b (Setup execution).
