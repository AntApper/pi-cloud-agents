## Security & Architecture Verification Checklist
- `formatPiAuthSecretName`, `formatGitHubSecretName`, and `formatRunSecretName` format standard hierarchical secret paths under `pi-cloud-agents/<stack>/...`.
- `putSecret` creates or updates secret values, tags, and optional KMS key encryption without leaking plaintext secrets in logs.
- `deleteSecret` automatically applies `ForceDeleteWithoutRecovery` for ephemeral run-scoped credentials and destroy operations, while retaining standard 7-day recovery windows for persistent stack credentials.
- `listRunScopedSecrets` and `listStackSecrets` paginate secret names matching prefix and strictly never invoke `GetSecretValueCommand`.
