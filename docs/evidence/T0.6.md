## Notes / follow-ups
- **ADR-5 Confirmed**: API keys should be synced by default (owner decision R1). OAuth providers that rotate refresh tokens must remain opt-in per provider with a clear ToS notice (owner decision R2).
- **GitHub Copilot & OpenRouter**: Exceptionally safe to sync because Copilot does not rotate its base token on session token generation and OpenRouter generates a permanent API key.
- **T5.9 OAuth Token Broker**: Confirmed as necessary for users wishing to run rotating OAuth subscriptions (Claude Pro/Max, ChatGPT Plus/Pro) across both local and cloud agents without login invalidation.
- **Assumption A10 Verified**: All individual credential entries (< 2 KB) and full `auth.json` files (< 10 KB) fit well within AWS Secrets Manager's 64 KB (65,536 bytes) limit.
