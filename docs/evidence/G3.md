# Gate G3 Evidence: Live Infrastructure Smoke Test Suite

## Plan
1. Implement `core/aws/infra-smoke.ts` orchestrating the full 11-step G3 live infrastructure smoke test.
2. Implement CLI runner `scripts/e2e-aws.ts` with `--region`, `--simulate`, `--live`, `--json`, and `PI_CLOUD_E2E` detection.
3. Author E2E test suite in `tests/e2e/aws-infra.test.ts` verifying all 11 lifecycle steps, cost estimation, and report formatting.
4. Verify both simulated mode (offline/CI) and live mode with zero orphaned resources.
5. Validate via `npm run e2e:aws -- --simulate` and `npm run check`.

## 11-Step Orchestration Summary
1. Deploy core stack `pi-cloud-agents-test-smoke-core` (S3 bucket, roles, log groups).
2. Upload `dist/image/app.zip` and `dist/controller.zip`.
3. Deploy image stack `pi-cloud-agents-test-smoke-image` (MicrovmImage + Controller).
4. Store mock LLM credentials into AWS Secrets Manager (`pi-cloud-agents/<stack>/pi-auth/mock-llm`).
5. Call `RunMicrovmCommand` with a test `LaunchPayload` pointing to a sample repo with `mock-llm`.
6. Poll `/v1/status` until `ready` -> submit test prompt -> wait for `idle`.
7. Verify controller idle keepalive and suspend evaluation.
8. Auto-resume via status request.
9. Terminate VM and observe `controller/last-run.json`.
10. Destroy image and core stacks.
11. Run kill-switch cleanup verification block (`npm run aws:cleanup -- --region us-east-1`).
