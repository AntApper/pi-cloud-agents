# Evidence: T4.7b — `/cloud attach`: input forwarding and controls

## Plan
1. Implement `extension/ui/input-handler.ts` handling input interception, streamingBehavior mapping (prompt/steer/followUp), `/cloud abort` and shortcut, and remote `extension_ui_request` resolution.
2. Wire `handleMirrorInput` into pi extension `input` event and register `/cloud abort` and `ctrl+alt+c` shortcut.
3. Add unit tests in `tests/unit/mirror-input.test.ts` validating prompt, steer, followUp, abort, image forwarding, and remote UI request/response handling.
4. Validate with `npm run check`.

## Implementation Details
- `extension/ui/input-handler.ts`:
  - `handleMirrorInput`: Intercepts `input` event in active mirror sessions:
    - Pass-through: If no mirror is attached, returns `{ action: "continue" }`.
    - Slash commands: Pass-through for `/cloud`, `/help`, etc. (`{ action: "continue" }`).
    - Standard prompt: Maps to `POST /v1/prompt` with `mode: "prompt"`, appends `cloud-msg` entry, and returns `{ action: "handled" }` to prevent local LLM invocation.
    - Steering: Maps `streamingBehavior === "steer"` to `mode: "steer"`, `steer: true`.
    - Follow-up: Maps `streamingBehavior === "followUp"` to `mode: "followUp"`.
    - Images: Supports attached image metadata reference formatting.
  - `handleCloudAbortCommand`:
    - Dispatches `/v1/abort` request to runner and notifies user.
  - `handleRemoteUiRequest`:
    - Intercepts remote `extension_ui_request` payloads (confirm, select, input), prompts the local user via `PiPrompter` / `PiUiContext`, and sends `extension_ui_response` back to the runner.
  - `registerInputHandling`:
    - Registers `pi.on("input", ...)` and keyboard shortcut `ctrl+alt+c` for quick abort.
- `extension/router.ts`:
  - Added `/cloud abort [runId]` subcommand to catalog and router.
- `extension/index.ts`:
  - Registered `registerInputHandling` on extension load.
- `tests/unit/mirror-input.test.ts`:
  - 9 unit tests verifying pass-through, slash command handling, prompt forwarding, steer, followUp, image attachments, abort command, remote UI request/response round-trips, and shortcut registration.
