# Evidence: T4.7c — Rich renderers and remote footer

## Plan
1. Implement `extension/ui/renderers/cloud-entry.ts` and `extension/ui/renderers/footer.ts` providing custom entry renderers for `cloud-msg` entries (assistant text, thinking blocks, bash tool boxes, edit diffs, file tools, errors, compaction) and responsive mirror footer.
2. Register `registerEntryRenderer("cloud-msg", ...)` and footer rendering in extension entrypoint and mirror session.
3. Add unit and snapshot tests in `tests/unit/mirror-renderers.test.ts` at 80 and 120 column widths.
4. Validate with `npm run check`.

## Implementation Details
- `extension/ui/renderers/cloud-entry.ts`:
  - `formatCloudMessage`:
    - Assistant messages: formats text lines and collapsible thinking blocks (`showThinking` & `expanded` options).
    - User messages: formatted with `> ` prefix.
    - Bash tool calls: formatted with pass/fail glyphs (`✓`/`✗`), command string, duration in ms, and bordered output box truncated with hidden lines notice when collapsed.
    - Edit tool calls: syntax-styled unified diff box with `+`, `-` lines and diff title.
    - File tools: compact single-line summaries for `read` (line counts), `write` (byte counts), `grep` (pattern and match count), `find` (pattern), and `ls` (entry count).
    - Unknown tools: safe JSON/formatted fallback.
    - System/Error notices: formatted with `▲` warning glyph.
  - `registerCloudRenderers`: registers `"cloud-msg"` custom entry renderer with pi `ExtensionAPI.registerEntryRenderer`.
- `extension/ui/renderers/footer.ts`:
  - `formatRemoteFooter`:
    - Renders responsive remote footer matching 07-ux-and-observability.md §2.5:
      - Left: `cloud <runId> · ● <status> · <currentTool> · turn <turns> · <tokens> tok · <cost> · ctx <contextPct>% · vm <uptime> · live <lastEventAge>`
      - Right: `<model> · thinking <thinking>`
    - Responsive at 80 columns (compact prioritized segment set) and 120 columns (full expanded telemetry).
  - `updateRemoteFooter`: updates footer via `ctx.ui.setFooter`.
- `tests/unit/mirror-renderers.test.ts`:
  - 10 unit tests covering assistant messages, thinking blocks, user inputs, bash tool boxes, edit diffs, file tool summaries, error notices, 80/120 col responsive footer, UI footer updating, zero-forbidden-glyph compliance, and entry renderer registration.
