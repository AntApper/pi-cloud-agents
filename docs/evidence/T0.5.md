## Plan
- Author `image/Dockerfile` v0 based on AL2023 minimal installing Node 22 (>=22.19), git, tar, gzip, which, findutils, procps, and pinned `@earendil-works/pi-coding-agent@0.85.1`.
- Implement `runner/pi-extensions/mock-llm.ts` registering custom provider `mock-llm` / model `scripted` with scripted zero-cost 2-turn execution (turn 1: bash tool call `echo hello > hello.txt`; turn 2: text completion).
- Implement `core/aws/pi-headless.ts` spike engine and `scripts/spike/pi-headless.ts` CLI running `pi --mode rpc --no-session --provider mock-llm --model scripted` with RPC stream parser, transcript validation, and metrics.
- Write unit test suite in `tests/unit/pi-headless.test.ts` validating Dockerfile v0, mock LLM provider, RPC stream event parser, transcript verification, and CLI arguments.
- Validate via `npm run check`, `npm run spike:pi-headless`, and `npm run aws:cleanup --dry-run`, then update decisions (assumption A2) and references §Measured.
