# Evidence: T4.7a — `/cloud attach`: mirror session core

## Plan
1. Implement `extension/ui/mirror.ts` managing mirror session state, historical replay from `/v1/entries`, live SSE streaming, widget/badge updating, local LLM guard, and session unbinding.
2. Implement `extension/commands/attach.ts` with `/cloud attach <runId>` and `/cloud detach` commands, integrated into `extension/router.ts` and `extension/index.ts`.
3. Add unit tests in `tests/unit/mirror-core.test.ts` covering session initialization, duplicate suppression, SSE stream handling, live widgets, and teardown.
4. Validate with `npm run check`.

## Implementation Details
- `extension/ui/mirror.ts`:
  - Implements `MirrorSession` class encapsulating mirror session lifecycle:
    - Session binding: creates or switches to `cloud: <shortRunId>` session in `PiUiContext`.
    - Session metadata: stores `cloud-run` custom entry (`runId`, `cursor`, `owner`, `status`, `endpoint`, `microvmId`, `repo`, `model`).
    - Historical replay: queries `/v1/entries?since=<cursor>`, strictly deduplicates via `seenEntryIds`, appends `cloud-msg` entries, and advances `cursor`.
    - Live streaming: subscribes to `RunClient.subscribeEvents` with `message_start` / `message_update` streaming deltas via `ctx.ui.setWidget("cloud-live", ...)`, tool execution status, turn finalization (`message_end` / `turn_end` / `agent_settled`), and `setStatus` badge updates.
    - Local LLM safety guard: `beforeAgentStartGuard` cancels local LLM agent execution when attached to a cloud mirror session.
    - Detach teardown: closes SSE streams, clears `cloud-live` widget, resets status badge to `cloud 0 running · 0 idle`.
  - Global registry: `getActiveMirrorSession`, `setActiveMirrorSession`, `createAndAttachMirrorSession`, and `detachActiveMirrorSession`.
- `extension/commands/attach.ts`:
  - Implements `handleCloudAttachCommand` and `handleCloudDetachCommand` with interactive `PiPrompter` run picker.
- `extension/router.ts` & `extension/index.ts`:
  - Routed `/cloud attach` and `/cloud detach`.
  - Registered `before_agent_start` guard hook and `session_shutdown` clean unbinding in extension runtime.
- `tests/unit/mirror-core.test.ts`:
  - 6 unit tests validating session initialization, historical deduplication, SSE streaming, local LLM guard, teardown, and detach command.
