# Evidence: T4.6 — `/cloud list` and `/cloud status <id>` detail card

## Plan
1. Implement `core/list.ts` for reading S3 manifests, merging with live MicroVM / `/v1/status` telemetry, computing cost estimates.
2. Implement `core/status.ts` for fetching run details, timeline milestones, event counters, model stats, and VM metrics.
3. Implement `extension/commands/list.ts` and `extension/commands/status.ts` using `extension/ui/kit.ts` with action menu and width-safe formatting.
4. Wire `list` and `status` subcommands into `extension/router.ts` and export through `core/index.ts`.
5. Add unit tests in `tests/unit/cloud-list-status.test.ts` covering merging, cost computation, and snapshot layouts at 80/120 columns.
6. Validate with `npm run check`.

## Implementation Details
- `core/list.ts`:
  - Discovers S3 manifests (`runs/*/manifest.json`, newest first, up to 50) using `ListObjectsV2Command` and `GetObjectCommand`.
  - Merges with active `ListMicrovms` state and live `/v1/status` summaries for non-terminal runs.
  - Implements `calculateMicrovmCost` using standard AWS pricing table ($0.0000276944/vCPU-s, $0.0000036667/GB-s) with mandatory `"est."` marker.
  - Formats token counts, elapsed durations, relative ages, and status badges.
  - Exports `listCloudRuns`, `extractShortRunId`, and helper formatters.
- `core/status.ts`:
  - Implements `fetchRunStatusDetails` and `formatRunStatusCard` matching 07-ux-and-observability.md §2.3.
  - Renders lifecycle timeline milestones with measured durations, event counters, tool calls breakdown, token metrics, workspace stats, VM cpu/mem/disk/egress stats, and checkpoint ages.
- `extension/commands/list.ts` & `extension/commands/status.ts`:
  - Implements `/cloud list` with responsive table layout (compact at 80 cols, full at 120 cols) and interactive action menu (attach, status, dashboard, logs, pr, stop).
  - Implements `/cloud status <runId>` with interactive run selector fallback and detail card rendering.
- `extension/router.ts`:
  - Connected `list` and `status` subcommands.
- `tests/unit/cloud-list-status.test.ts`:
  - 7 unit tests covering pricing calculation, token formatting, S3 manifest merging, active VM state reconciliation, table width safety at 80/120 cols, detail card layout matching §2.3, and command handlers.
