# Evidence: T4.10 — `/cloud update` and `/cloud destroy`

## Plan
1. Implement `core/lifecycle-ops.ts` for orchestrating image drift checking, artifact upload, CloudFormation stack updates, version pruning, S3 bucket purging, secret force-deletion, and local config cleanup.
2. Implement `extension/commands/lifecycle-ops.ts` providing command handlers for `/cloud update` and `/cloud destroy`.
3. Wire `update` and `destroy` subcommands into `extension/router.ts` and CLI `cli/main.ts`.
4. Add unit tests in `tests/unit/cloud-update-destroy.test.ts` testing drift detection, artifact upload, stack updates, version pruning, and full destruction.
5. Validate with `npm run check`.

## Implementation Details
- `core/lifecycle-ops.ts`:
  - `executeCloudUpdate`: Compares local artifact SHA with active MicroVM image version via `MicrovmImageManager.checkImageDrift`. If update needed, uploads new runner and controller zips, deploys updated image stack via CloudFormation (`StackDeployer.deployStack`), awaits new image version activation via `waitForImageReady`, prunes older versions via `pruneVersions(keep=2)`, and refreshes pi config bundle via `syncPiConfig`.
  - `executeCloudDestroy`: Discovers active MicroVMs in region and terminates them, purges all object versions and delete markers from S3 bucket via `StackDeployer.emptyBucket`, force-deletes Secrets Manager secrets under `/pi-cloud-agents/<stack>/*`, deletes image and core CloudFormation stacks, and deletes local configuration and step ledger files.
- `extension/commands/lifecycle-ops.ts`:
  - `/cloud update`: Displays dry-run drift summary or executes update workflow with live progress and version summary.
  - `/cloud destroy`: Provides interactive warning and confirmation dialog with `--yes` and `--force` support, reporting full cleanup summary.
- `cli/main.ts`:
  - Connected `update` and `destroy` subcommands in standalone CLI.
- `tests/unit/cloud-update-destroy.test.ts`:
  - 5 unit tests covering drift detection, full update flow, stack teardown, bucket purge, secret force-deletion, and CLI/extension handlers.
