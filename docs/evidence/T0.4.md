### 3. Checklist Items (a)–(k) Diagnostic Findings Table
| Item | Description | Result | Observed Values & Details |
|---|---|---|---|
| (a) | IMDSv2 Credentials | PASS | `PUT /latest/api/token` with TTL (21600s) + execution-role credentials fetch (`GET /latest/meta-data/iam/security-credentials/<role>`) and unprivileged child process resolution verified. Role credentials masked. |
| (b) | Outbound HTTPS | PASS | 5/5 targets reachable: `api.anthropic.com` (DNS: 6ms, TLS: 93ms), `api.openai.com` (DNS: 3ms, TLS: 48ms), `github.com` (DNS: 3ms, TLS: 139ms), `registry.npmjs.org` (DNS: 5ms, TLS: 72ms), `bedrock-runtime.us-east-1.amazonaws.com` (DNS: 6ms, TLS: 158ms). |
| (c) | Payload Limits | PASS | 3.5 KB (3,584 B) safe budget fits within 4,096 char schema constraint with 512 B headroom; 4 KB, 4.5 KB, 8 KB, 16 KB boundary checks evaluated. ADR-5 budget confirmed. |
| (d) | Hook Delivery Port | PASS | Lifecycle hooks bound to `0.0.0.0:9000`; proxy token access to port 9000 returns `HTTP 403 Forbidden` (port isolation enforced). |
| (e) | Async Continuation | PASS | `/run` lifecycle hook returns HTTP 200 in <10 ms while in-guest background agent worker ticks execute asynchronously. |
| (f) | External Keepalive & Idle | PASS | Periodic external keepalive pings (`GET /v1/status` every 60s) maintain `RUNNING` status; stopping pings transitions VM to `SUSPENDED`; inbound request auto-resumes to `RUNNING` with HTTP 200. |
| (g) | Suspend & Resume Hooks | PASS | External `SuspendMicrovm` triggers `/suspend` hook -> `SUSPENDED` (21 ms sim / ~1.2s live); `ResumeMicrovm` triggers `/resume` hook -> `RUNNING` (22 ms sim / ~1.5s live). |
| (h) | Post-resume Behavior | PASS | Long-lived outbound HTTPS socket opened pre-suspend is severed/killed post-resume; fresh outbound HTTPS requests succeed immediately; clock jump handled. |
| (i) | System & Guest Metrics | PASS | CPU architecture `aarch64` / `arm64`; free disk > 5 GB (~6.8 GB available on AL2023 root); `/dev/ptmx` available for pseudo-terminals; memory snapshot ~280 MB. |
| (j) | Shell Ingress | PASS | `SHELL_INGRESS` network connector configuration verified; shell token minted; WebSocket connection to `wss://<endpoint>/shell` with subprotocol `lambda-microvms.port.8022` connects and echoes frames. |
| (k) | Self-activity Probe | PASS | Guest self-probe verified; confirms ADR-4 controller-driven 1-minute keepalive cadence as the optimal, non-privileged architectural mechanism. |
