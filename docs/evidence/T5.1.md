# Evidence: T5.1 — In-VM secret redaction extension and transcript sanitizer

## Plan
1. Create `runner/pi-extensions/redact.ts` implementing in-VM redaction extension that intercepts `tool_result` and `message_end` events.
2. Implement robust environment variable parser supporting JSON maps, JSON arrays, comma-separated lists, and auto-detection of sensitive keys.
3. Apply deep recursive redaction across SSE/WS payloads (`runner/api.ts`, `runner/ws-rpc.ts`) and mirrored session transcripts (`runner/state.ts`).
4. Add unit test suite in `tests/unit/redact-extension.test.ts`.
5. Validate with `npm run check`.

## Implementation Details
- `runner/pi-extensions/redact.ts`:
  - `parseRedactionEnv`: Parses `PI_CLOUD_REDACT_ENV` (JSON object, array, or comma-separated list) and automatically inspects standard sensitive credential environment variables (such as `GITHUB_TOKEN`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, AWS session tokens, and passwords).
  - `redactText`: Redacts matching secret strings by replacing them with `[REDACTED:<NAME>]` (or `[REDACTED]`), sorting rules descending by length to match longer secrets first. Automatically masks 12-digit AWS account IDs with `<ACCOUNT_ID>`.
  - `redactObject`: Deep recursive sanitizer for arbitrary objects, arrays, Error instances (messages and stacks), and nested structures, with circular reference protection.
  - Extension factory `default(pi)`: Registers interceptors on `tool_result` (redacting text content blocks and tool details) and `message_end` (redacting assistant messages) before results enter transcripts or LLM context.
- `runner/pi-config.ts`:
  - Assembles `PI_CLOUD_REDACT_ENV` JSON payload during in-VM environment initialization containing provider secrets and GitHub tokens.
- `runner/state.ts`:
  - Sanitizes raw session chunks and flushed session transcripts (`session.jsonl`) using `redactText` before storing to S3 or local storage sink.
- `runner/api.ts` & `runner/ws-rpc.ts`:
  - Applies `redactObject` to all SSE stream frames, JSON REST responses, and WebSocket RPC messages dispatched to clients.
- `tests/unit/redact-extension.test.ts`:
  - 12 unit tests verifying rule parsing, length-descending sorting, text redaction, object/array/error redaction, circular reference handling, and pi lifecycle event interception.
