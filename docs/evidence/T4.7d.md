# Evidence: T4.7d — Durability: auto-reattach, reconnect, laptop-close semantics

## Plan
1. Implement `extension/ui/durability.ts` providing session detection on `session_start`, auto-reattach with status indications ("reconnecting...", "resuming MicroVM..."), suspended VM auto-resumption, terminated state handling, and exponential reconnect backoff with jitter.
2. Wire durability hooks into `extension/index.ts` and update `/cloud list` to highlight active mirror sessions ("open mirror").
3. Add unit tests in `tests/unit/mirror-durability.test.ts` covering session start auto-reattach, suspended VM handling, terminated VM detection, backoff reconnect, and cursor deduplication.
4. Validate with `npm run check`.

## Implementation Details
- `extension/ui/durability.ts`:
  - `computeReconnectDelay`: Implements exponential backoff (`baseMs * 1.5^attempt`) with bounded jitter (`±20%`) and maximum delay cap for dropped network connections or host sleep.
  - `detectCloudRunMetadata`: Scans session entries for `cloud-run` custom entry and extracts `CloudRunSessionMetadata` (`runId`, `cursor`, `owner`, `endpoint`, etc.).
  - `autoReattachSession`:
    - Auto-reattaches on `session_start` (startup, `pi -c`, `/resume`).
    - Indicates `reconnecting...` status during connection probe.
    - Handles suspended MicroVMs: transitions to `resuming MicroVM...` and notifies user.
    - Handles completed or terminated runs: displays final manifest state, sets status badge (`completed`/`terminated`), and offers continuation commands.
    - Replays historical entries missed since the last saved `cursor` with zero duplicate entries.
    - Subscribes to live SSE event stream with auto-reconnect backoff.
  - `handleSessionStartDurability` & `handleSessionShutdownDurability`: Lifecycle hooks wired to extension runtime.
- `extension/commands/list.ts`:
  - Highlights active mirror sessions with `[open mirror]` tag and offers `Detach mirror session` in interactive action menu.
- `extension/index.ts`:
  - Hooked `handleSessionStartDurability` on `session_start` and `handleSessionShutdownDurability` on `session_shutdown`.
- `tests/unit/mirror-durability.test.ts`:
  - 7 unit tests covering backoff delay calculations, metadata detection, running VM auto-reattach, suspended VM resuming status, terminated run notifications, session start hook invocation, and shutdown teardown.
