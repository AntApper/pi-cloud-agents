## Plan
- Create in-memory zip bundle builder for ARM64 container with Node.js, port 9000 lifecycle hooks, and port 8080 app server (HTTP, WebSocket, SSE).
- Implement AWS MicroVM orchestration modules in `core/aws/` for image creation, run, auth token minting, proxy requests, WS/SSE verification, and lifecycle transitions.
- Implement CLI spike script `scripts/spike/hello-microvm.ts` supporting `--region`, `--dry-run`/`--simulate`, and live execution with cleanup guarantee.
- Add unit tests in `tests/unit/hello-microvm.test.ts` verifying bundling, payload encoding/decoding, token header construction, port isolation, and simulation.
- Validate offline simulation, check glyphs and typecheck, run live tests if credentials available, and verify cleanup block.

## Changes
- files:
  - `package.json`: added `@aws-sdk/client-iam` dependency and updated `"spike:hello-microvm"` script to `tsx scripts/spike/hello-microvm.ts`.
  - `core/aws/zip.ts`: pure TypeScript deterministic in-memory ZIP archive generator with fixed timestamps and CRC32 calculation.
  - `core/aws/hello-bundle.ts`: guest bundle builder creating Dockerfile (AL2023 base, Node 22) and in-VM `server.js` (port 9000 hooks, port 8080 HTTP/WS/SSE app server), plus 3 KB payload generator.
  - `core/aws/hello-microvm.ts`: end-to-end spike engine supporting live AWS execution and offline high-fidelity simulation, token header creation, WebSocket RFC 6455 framing, SSE streaming, port 9000 403 isolation, suspend/resume lifecycle transitions, cost estimation, and Unicode table formatter.

  - `core/index.ts`: exported new AWS zip, bundle, and hello-microvm modules.
  - `scripts/spike/hello-microvm.ts`: CLI entry point with `--region`, `--simulate`, `--live`, `--json`, and `--keep-resources` support.
  - `tests/unit/hello-microvm.test.ts`: 12 unit tests covering zip determinism, Dockerfile/server generation, payload sizing, pricing, mock server, token headers, port 9000 403 denial, WS echo, SSE stream, and simulation.
